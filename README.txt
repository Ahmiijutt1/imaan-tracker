IMAAN & ZIKR TRACKER - hosting folder

Upload everything in this folder (index.html, sw.js, manifest.webmanifest and the icons folder) to a free host such as GitHub Pages.

To update the app later: replace index.html with the new version (keep the name index.html) and upload it again. People get the new version the next time they open or refresh the page. Do not rename or delete the other files.

Your tracker data lives in each person's own browser. Updating the app never erases it. Use Backup before big changes.
